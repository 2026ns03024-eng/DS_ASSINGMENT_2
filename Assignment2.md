Title: Distributed Resource Sharing and Processing System using Peer-to-Peer and Cluster Computing
	Design and implement a distributed resource sharing and processing system in which multiple peer nodes communicate directly with each other to share resources and requests, while a cluster of computing nodes is used to perform computationally intensive tasks. The system should demonstrate the decentralized nature of Peer-to-Peer communication and the parallel processing capability of Cluster Computing. The implementation should allow requests to be exchanged between peer nodes and computational tasks to be distributed among cluster nodes, demonstrating how both architectures can be used together to improve resource sharing, processing efficiency, and system scalability.

Minimum requirements
•	At least 4 peer nodes participating in the distributed system.
•	Implement direct communication between peer nodes without a central coordinator for peer communication.
•	Demonstrate resource/request sharing between multiple peers.
•	Implement a cluster consisting of a master/coordinator and multiple worker nodes.
•	Distribute computational tasks among the worker nodes.
•	Demonstrate parallel execution of multiple tasks.
•	Show how a request from a peer can be processed using the cluster resources.
•	Demonstrate the addition or removal of a node and analyze its effect on the distributed system.
•	Compare the Peer-to-Peer and Cluster Computing approaches based on communication, resource sharing, scalability, and processing
